BEAUTY & BLOOMS - PHP / MYSQL / BOOTSTRAP 5
===========================================
1) Extract this ZIP.
2) Copy folder Beauty_and_Blooms to C:\xampp\htdocs\
3) Open XAMPP Control Panel. Start Apache and MySQL.
4) Open http://localhost/phpmyadmin
5) Import database.sql. It creates database beauty_blooms.
6) Open http://localhost/Beauty_and_Blooms/setup_admin.php once.
7) Delete setup_admin.php after admin is created.
8) Website: http://localhost/Beauty_and_Blooms/
9) Admin: http://localhost/Beauty_and_Blooms/admin/login.php

Included: homepage, shop, category filter/search, product details, register/login,
session cart, demo checkout/order history, profile summary, about/contact pages,
admin dashboard, product add/delete, order and customer lists.

Notes:
- This is a student/demo starter project and has not been tested on your computer.
- Checkout is simulated. No real payment gateway is connected.
- Product images, Bootstrap and fonts use online CDN/image URLs; internet is needed.
- Local XAMPP is for testing. Public hosting requires a compatible PHP/MySQL host.
- Change BASE_URL in config.php if you rename the project folder.
- Change database credentials in config.php if your MySQL credentials differ.
- Do not publish real customer information or passwords.
